A diagnostic order the whole workshop can follow.

TorqueCode gives technicians and service writers a plain-language code reference and a repeatable process. Use it to reduce guesswork, standardise onboarding, and explain a fault to a customer without overselling a part.

The workflow

Six steps, same order every time.

A trouble code names a circuit, not a component. This is the order we recommend before any part is quoted.

01 · Confirm the complaint and the vehicle

Record the make, model, engine, mileage and the customer's exact symptoms. Check for previous work, aftermarket wiring and recalled components. A code without context is easy to misread.

02 · Scan all modules, not just the ECM

A warning light often starts in one system and shows up in another. Save the full report before clearing anything. Network and body codes can explain a powertrain symptom that looks unrelated.

Look up unfamiliar codes in our code library and keep the five-character identifier with the job card.

03 · Read freeze frame and live data

Freeze frame tells you the conditions when the fault set: load, speed, temperature and fuel trim. Live data shows what the sensor reports right now. The gap between the two is often the most useful clue in the job.

04 · Test the circuit before the part

Verify power, ground, continuity and signal at the connector. A sensor replacement without a voltage-drop or resistance check is a guess, and comeback work is expensive for a workshop.

05 · Repair, clear and recheck

Clear the code only after the repair is made. Run the vehicle through the same conditions captured in freeze frame, then rescan. A code that returns immediately means the cause is still present.

06 · Document the result for the customer

Write down the code, the measurement that confirmed the fault and the recheck result. Clear wording protects the workshop and helps the next technician who sees the vehicle.
