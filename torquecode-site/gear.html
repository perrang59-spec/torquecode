What earns its place in the toolbox

01 · OBD-II code reader

The basic tool for anyone working on a modern car. It reads and clears diagnostic trouble codes and identifies which system set them. A reader gives you the five-character code you need before you search our code library, and it lets you confirm that a repair actually fixed the fault.

Look for: reliable OBD-II/EOBD support, clear code descriptions, freeze-frame data and a readable screen. Live data is a bonus, not a requirement for a first tool.

Typical budget: about $20 – $60

See OBD-II code readers on Amazon →

02 · Scan tool with live data

When a code points to a sensor or a system, live data shows what that sensor is actually reporting while the engine runs. Comparing commanded and actual values is often the fastest way to separate a bad sensor from a wiring, vacuum or mechanical problem.

Look for: live data graphing, mode 6 test results, and support for the makes you actually work on. Advanced bidirectional controls are useful but cost more — buy them when you need them.

Typical budget: about $70 – $200

See live-data scan tools on Amazon →

03 · Digital multimeter

The cheapest way to test a circuit. Continuity checks find broken wiring, voltage-drop tests find high resistance, and resistance checks verify sensors. A code reader can tell you a circuit is out of range; a multimeter tells you why.

Look for: a robust input fuse, clear display, test leads in good condition, and a size that fits in your hand. Accuracy matters more than extra functions.

Typical budget: about $25 – $80

See digital multimeters on Amazon →

04 · Tyre pressure gauge

Underinflated tyres increase rolling resistance, wear out early and change handling. A reliable gauge is the simplest fuel-economy tool you can own, and it belongs in the glovebox rather than the workshop.

Look for: a gauge that reads in both kPa/bar and psi if you travel, a comfortable head, and a calm habit of checking pressures when the tyres are cold.

Typical budget: about $10 – $40

See tyre pressure gauges on Amazon →

05 · Vacuum and smoke test kit

Vacuum leaks and EVAP leaks cause rough idle, lean codes and failed emissions tests. A hand vacuum pump or a smoke machine lets you find the leak instead of replacing sensors one at a time.

Look for: a kit suited to the pressure ranges you need, quality fittings and a safe, controlled way to introduce smoke into the intake or EVAP system.

Typical budget: about $25 – $120

See vacuum and smoke test kits on Amazon →

06 · Fuel pressure test kit

Low fuel pressure can mimic a weak pump, a clogged filter, a bad regulator or an injector fault. A gauge on the rail tells you which direction to look before you spend money on parts.

Look for: adapters for your vehicle's test port, a gauge with a useful range, and a clear understanding of the spec for your engine — pressures vary widely.

Typical budget: about $30 – $100

See fuel pressure test kits on Amazon →

07 · ECU memory saver

Disconnecting a battery can wipe learned adaptive values, radio codes and window settings. A memory saver keeps a small supply to the ECU while you work, so you are not starting from scratch afterwards.

Look for: a unit that matches your vehicle's electrical system, short-circuit protection and clear instructions. Used incorrectly, any battery device can cause damage — follow the manual.

Typical budget: about $20 – $70

See ECU memory savers on Amazon →
